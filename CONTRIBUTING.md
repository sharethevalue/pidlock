# Contributing

Share the Value is open and community-run. Thank you for helping.

## Ways to contribute

- **Issues**: report problems, unclear wording, or gaps in the paper or spec.
- **Discussions**: ask questions and explore ideas before they become proposals.
- **Pull requests**: fix typos, improve docs, or add code. Keep each PR focused on one change.
- **Spec proposals**: for changes to the protocol, open an issue titled `Proposal: <short name>` describing the problem, the proposed change, and any trade-offs. Once there is rough agreement, open a PR against the spec.

## What to build first

1. **Consent and vault spec**: a clear format for what a person shares, with whom, and how access is switched on or off.
2. **Reference Pidlock vault**: an on-device implementation that keeps raw data local.
3. **Verified-sale attestation**: a way for merchants to confirm a sale and its return status.
4. **Holdout-lift measurement method**: a simple, transparent way to measure lift against a holdout group.
5. **Pilot partner outreach**: help find and talk with a challenger platform for the first pilot.
